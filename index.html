GPU Memory Buffer (The Stride)

01. THE VERTEX

The fundamental unit of drawing. Each corner has an (X,Y) for screen position and (U,V) for texture mapping.

02. THE STRIDE

Memory optimization. Packing X,Y and U,V together allows the GPU to read all data for one point in a single memory fetch.

03. UV MAPPING

Think of it as wrapping paper. The image is "pinned" to the vertices. Scaling the vertices scales the image automatically.

04. DRAW CALLS

The GPU "paints" the buffer. Every frame, the array is uploaded to VRAM and rendered instantly. This is why Lightning is smooth.
